# habit-tracker

`index.html` をブラウザーで開いて使う習慣管理アプリです。記録はブラウザーに保存されます。

## 日付・記録・グラフ

- ホームの日付欄を左右にスワイプすると前後の日へ移動します。矢印、日付入力、「今日へ」も使えます。未来日は選択できません。
- 筋トレに「休憩する」を追加しました。セットを保存すると休憩日を解除します。既にセットがある日は、セットを削除してから休憩日にできます。
- 体重には「測らなかった」を保存できます。未入力とは区別し、平均には含めません。
- 筋トレの実施日は間隔を空けずに等間隔で表示します。直近5回のボリュームと最大セットの重さ×回数をグラフ上に表示し、全セットの内容も直近5回の表で確認できます。重量種目のボリュームは重量×回数の合計、自重種目は回数の合計です。
- グラフと履歴表は各ブロック内だけで横スクロールできます。グラフの縦軸目盛りは左右両端にあります。
- 部位の履歴は行が部位、列が日付です。左に最新日、右に過去6日を配置します。
- ホーム下部に総活動時間・得点の日別／週別／月別グラフがあります。得点の対象は従来のホームの合計と同じ0/1/2型の習慣です（To doの進捗評価は個別グラフで確認）。
- 各項目にも週別／月別グラフがあります。時間・得点・筋トレは合計、体重と起床／就寝の基準差は記録日の平均です。週は月曜日始まりで、選択日までの直近12週／12か月を表示します。進行中の週・月は選択日までの集計です。
- 未記録日を0として補完せず、前後の記録点を線で結びます。明示的な0点・0分・休憩日は0として集計します。

## ローカルの変更確認

GitHub Desktopでこのリポジトリを開くと、Changesに未コミットの変更が表示されます。差分とブラウザーでの動作を確認してコミットしてください。

## 回帰テスト

Node.js、Playwright、Microsoft Edgeがある環境で実行できます。

```powershell
node tests/regression.cjs
```

Playwrightが別の場所にインストールされている場合は、`PLAYWRIGHT_MODULE` 環境変数にそのパッケージの絶対パスを設定してください。Chromeを使う場合は `BROWSER_CHANNEL=chrome` を指定します。

テストは一時的なローカルサーバーと独立したブラウザープロファイルを使い、外部通信を遮断します。日付移動、欠測日の接続、週・月の集計、保存後の再読込、筋トレの履歴・休憩日、幅320〜1440pxでの横幅を確認します。実際の記録には触れません。
